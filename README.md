 Isabelle Augu

Site vitrine pour l'artiste peintre Isabelle Augu.

🌐 **Site en ligne** : [https://isabelleaugu.com](https://isabelleaugu.com)

## 📋 Description

Site web moderne présentant les œuvres et le travail artistique d'Isabelle Augu. Le site offre une expérience visuelle optimisée avec une navigation fluide et un design responsive.

## 🛠️ Technologies utilisées

- **React 19** - Bibliothèque JavaScript pour l'interface utilisateur
- **Vite 7** - Outil de build rapide et moderne
- **TailwindCSS 4** - Framework CSS utility-first
- **React Router DOM** - Navigation entre les pages
- **Motion** - Animations fluides et interactives
- **React Lightbox** - Galerie d'images avec zoom
- **React Helmet** - Gestion des métadonnées SEO
- **React Lazy Load** - Chargement optimisé des images

## 🚀 Installation

```bash
# Cloner le repository
git clone https://github.com/LiamOgu/isabelle-augu.git

# Accéder au dossier du projet
cd isabelle-augu

# Installer les dépendances
npm install
```

## 💻 Commandes disponibles

```bash
# Lancer le serveur de développement
npm run dev

# Créer le build de production
npm run build

# Prévisualiser le build de production
npm run preview

# Linter le code
npm run lint
```

## 📦 Déploiement

Le site est déployé sur **Vercel** avec une configuration optimisée pour les applications React.
